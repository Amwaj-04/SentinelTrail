How to explore this demo

  1. Run Demo Incident generates a short, realistic burst of suspicious file activity in a sandboxed folder — no real system access involved.
  2. Open any case file to follow its Evidence Trail — from the initial signal through analysis, impact, and recommended response.
  3. Expand Evidence Integrity inside a case, edit its record, then click Verify Evidence Trail — the chain will flag exactly which record was altered.
  4. Reset demo data clears everything so you can run the scenario again.
